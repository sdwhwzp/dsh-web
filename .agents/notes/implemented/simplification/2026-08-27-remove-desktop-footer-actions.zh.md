# Agent Note: 移除桌面底部入口

Status: implemented

## Problem

remote-web-ui 浏览器插件会向桌面侧边栏底部同时贡献“检查更新”和“远程访问”入口。这些管理员控件占据每个桌面页面的左下角导航区域，包括已经在侧边栏之外管理配对与更新的部署。

## Decision

浏览器插件不再向 `sidebar.remote` 或 `sidebar.footer.action` 注册贡献。插件设置卡片、配对链接接受流程、移动端在线流程、已配对远程桌面通道、现有已配对设备会话，以及仅限 loopback 的配对和更新路由保持运行。未配对设备提示改为联系管理员，不再指向不存在的侧边栏入口。

## Alternatives considered

- 用 CSS 隐藏两个按钮：否决，因为控件仍会挂载并运行探测，也仍存在于无障碍树中。
- 关闭整个 remote-web-ui 插件：否决，因为这也会停止已配对远程会话并移除 host 路由。
- 保留其中一个入口：否决，因为目标是左下角不出现这两项管理员控件。

## Consequences

- 桌面页面左下角不再显示“检查更新”和“远程访问”。
- 现有已配对设备与远程通道继续工作。
- 管理员通过仅限 loopback 的控制端点或其他管理员工具签发配对链接并执行更新。
- 注册测试断言 settings 状态变化不会添加任何一个底部贡献。
