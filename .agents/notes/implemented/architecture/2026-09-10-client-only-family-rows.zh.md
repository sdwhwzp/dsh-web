# Agent Note: 仅浏览器家族行

Status: implemented

[English](2026-09-10-client-only-family-rows.md) | 中文

## 问题

部署可以用按账号隔离的网关实现替代家族插件的共享 Host。停用原行也会把浏览器界面从活动行登记表移除，使替代 API 失去入口。

## 决策

壳行配置中的显式布尔字段 `clientOnly` 保留活动行登记及其清理函数，但跳过真实 Host 插件的导入和启动。部署负责替代 API 及其鉴权。非法字段值生成配置降级记录，且不会激活该行。

## 考虑过的替代方案

启用共享 Host 会在私有账号调度器之外恢复一个全局调度器。让浏览器忽略停用行则违背常规插件开关语义。单独声明仅浏览器模式可以同时保留这两项要求，无需对插件名称作特殊处理。

## 影响

现有停用行行为保持不变。仅浏览器行需要兼容的替代 API；壳不推断其就绪状态，也不提供账号隔离。验证覆盖行发现、清理及非法配置拒绝。
