# Agent Note: 任务看板执行账号归属

Status: implemented

## Problem

Host 调度器的生命周期长于创建任务的浏览器请求。支持账号的 Session 服务在创建、提交 Prompt、读取名册和历史流时要求认证身份；不携带身份的后台调用无法执行或观察任务。

## Decision

仅管理员可访问的看板通过 Connection 验证每个请求；Connection 未暴露认证接口时，使用现有签名身份 provider 兼容路径。Host 专用的 `taskPrincipals` 映射与新任务、显式执行或计划绑定写入同一次原子账本事务。浏览器导入和仅供审计的 initiator 不能建立所有权。已有所有者的任务只能由该所有者修改，导入不能覆盖已有所有者的任务。

每次执行和后台观察均使用保存的所有者，并在 gateway 调用及权限命令前重新检查有效账号 provider。会话名册和复用依据与该所有者关联。持久化所有权无效时拒绝启动并保留账本。没有部署身份服务的独立 Host 保留本地行为；已绑定身份在 provider 消失时不会回退到匿名执行。

## Alternatives considered

固定管理员身份会将他人的工作和模型用量归给虚构身份，并可能越过账号撤销。因此 Host 不从配置或用户表中自行选择管理员。

仅保存请求内身份可以授权手动执行，但浏览器断开或 Host 重启后会丢失归属。调度器需要独立于传输令牌的持久化所有权。

单独的所有权文件需要跨任务状态和所有权的事务。可选的 Host 专用账本字段保留已有单写者与原子 rename 生命周期，无须改变浏览器任务记录。

## Consequences

历史及导入卡片保持无所有者状态，直到认证管理员显式执行或设置计划。无所有者或身份已撤销的计划执行在创建 Session 前失败，权限已撤销的观察者不能继续接收 SSE 更新。共享看板仍对管理员可见；本适配不开放普通账号访问，也不创建各账号独立看板。

定向测试覆盖已验证请求身份的传递、等待操作之间撤销账号、重启后持久化计划执行、历史流观察、跨账号修改拒绝、伪造传输身份拒绝以及损坏所有权数据的原文件保留。SDK gateway 兼容决策继续由[任务看板 SDK 记录](2026-08-28-task-board-sdk-0.1.2-alpha.1.md)管理。
