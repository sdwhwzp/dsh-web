# Agent Note: 账号独立的 SSH 连接

Status: implemented

## Problem

共享 SSH 存储和连接池使别名成为全局标识。仅在网关过滤列表无法隔离跳板机、隧道、凭据和 Agent 工具，也阻止了账号独立编辑同名连接。

## Decision

显式启用的账号模式在每次 HTTP、WebSocket 或工具操作前，解析认证身份并检查当前部署权限。每个账号拥有以身份来源和 id 的哈希命名的文件及连接引擎。各路由在该引擎内保留原有 SSH 行为。凭据修改和别名删除仅使该引擎的连接失效。复用缓存引擎前会重新检查账号角色。 账号引擎每 30 秒复核权限，并关闭已撤权的连接池和固定隧道。

普通账号提供密码或私钥内容。服务器密钥文件、SSH agent、配置导入和任意本地路径的 Agent 传输仍属于管理员能力；浏览器文件传输仅暂存上传或下载的字节。网关继续负责网络目标策略、账号权限变更及关闭已撤权的 WebSocket。

旧别名依据网关持久化归属记录一次性复制，未认领别名仅归最早创建的管理员。原文件保留为备份。空账号文件也持久化，防止重启后恢复已删除的旧连接。

## Alternatives considered

在网关给别名加前缀需要改写每个请求、响应、隧道 id、跳板链和工具调用。账号独立的引擎复用 SSH 实现，使这些标识自然局限于账号内，无需另一套转换协议。

允许普通用户指定 Host 私钥路径或 agent 会授予服务账号凭据的访问权。私钥内容支持密钥认证，同时避免授予这类访问权。

## Consequences

网关的 `TENANT_SSH_ENABLED` 和 SSH 插件的 `accountIsolation` 必须在同次部署中开启。认证 Host 身份须传入 Agent 工具执行，缺失身份时拒绝访问。账号路由、同名别名、旧配置迁移、私钥认证、隧道隔离和权限撤销均有行为测试。普通 Agent 的本地路径传输须改用浏览器传输页。
